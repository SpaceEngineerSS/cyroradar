## [1.0.0] - 2026-04-28

### Added (Initial Production Release)
- **WebGPU FDTD Engine:** Adjoint-State Full-Waveform Inversion for high-resolution subsurface tomography.
- **PolSAR Engine:** Pauli decomposition and H/A/Alpha theorem for polarimetric analysis.
- **Uncertainty Quantification (UQ):** Markov Chain Monte Carlo (MCMC) engine for geophysical parameter inference.
- **Bayesian Counter-Hypothesis Engine:** Evaluates BBR anomalies against Liquid Water, Smectite Clay, and Surface Clutter hypotheses.
- **Topographic Static Correction:** Datum correction using per-trace vertical time-shifts from MOLA elevation data.
- **Geophysical Colormaps:** 7 scientifically calibrated palettes.
- **Scientific Data Export:** CSV/JSON export and high-resolution PNG capture.
- **Dual-Mode Architecture:** Explorer (educational) and Analyst (research) modes.
- **PDS API Client:** NASA Planetary Data System Orbital Data Explorer REST API integration.
